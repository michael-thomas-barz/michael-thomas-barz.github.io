Taylor series in two variables

Reminders of calculus

Remember that, in one variable, the Taylor series of f(x) centered at x = a was

f(x) ≈ f(a) + f′(a)(x − a) + ½f″(a)(x − a)² + ⋯

We should think of this as approximating the function using what we know at one point.

Going to two variables

In two variables, there isn’t just a single first or second derivative—there are many! So, when you're doing Taylor series in 2 variables, you use the same basic format as in 1-dimension, but you need to account for all possible derivatives. How good is the Taylor approximation?

An approximation is only useful if you know how good of an approximation it is. These Taylor series give you an approximation to some function -- how good is that approximation?

How large can the error be?

Write T₁ for the linear Taylor polynomial and T₂ for the quadratic one. Choose a rectangle containing the center (a, b) and the point (x, y), with f smooth throughout that rectangle.

Error in the linear approximation

Always go to the next order to calculate an error bound: for a first-order approximation, bound the second derivatives.

|f(x, y) − T₁(x, y)| ≤ M₂/2 (|x − a| + |y − b|)²

Here M₂ is the maximum absolute value of any second derivative——anywhere in the rectangle. Bound the derivatives over the whole rectangle, not just at its center.
